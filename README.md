# 📦 Inventory Management System

A full-stack web application to manage inventory efficiently with a user-friendly interface and robust backend.

---

## 🚀 Tech Stack

### Frontend
- React.js
- HTML, CSS, JavaScript

### Backend
- Spring Boot (Java)
- REST APIs

### Database
- MySQL

---

## ✨ Features

- Add, update, and delete inventory items
- View inventory list in real-time
- REST API integration between frontend and backend
- Responsive and user-friendly UI

---

## 🏗️ Project Structure

InventoryProject/
 ├── inventoryApplication/   # Backend (Spring Boot)
 ├── frontend/               # Frontend (React)
 └── docs/                   # Documentation (PPT)

---

## 🔄 Workflow

1. User interacts with the frontend UI  
2. Frontend sends API requests to backend  
3. Backend processes logic and interacts with database  
4. Data is returned and displayed on UI  

---

## ⚙️ Installation & Setup

### 🔹 Backend

cd inventoryApplication  
mvn spring-boot:run  

---

### 🔹 Frontend

cd frontend  
npm install  
npm start  

---

## 🌐 API Communication

- Frontend communicates with backend using REST APIs  
- JSON is used for data exchange
